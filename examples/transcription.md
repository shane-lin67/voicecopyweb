# 从一段口播到可编辑文案

## 先获得原始转写

1. 用自己的短音频或视频测试，避免第一次就上传超长素材。
2. 按 README 启动服务，浏览器打开终端显示的地址，填写访问口令。
3. 上传本地文件，等待识别完成。第一次可能要先下载模型。
4. 核对姓名、数字、术语和明显漏句，复制并保留这份原稿。

## 再交给 AI 整理

以下步骤发生在你自己的 AI 助手中，网页不会自动执行：

> 请参考配套 Skill 整理下面的转写：先保留原文，再给我一版只删除口头语和重复句的稿子，最后列三条要点。不要新增事实，不确定的词标为“待核对”。原文：[粘贴转写]

区分识别错误与表达问题：前者需要回听素材，后者才适合改写。整理后的稿子不会自动发到社交平台。
